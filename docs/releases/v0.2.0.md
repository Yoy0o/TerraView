TerraView 0.2.0 是首个对外版本。TerraView 是基于 three.js 的 WebGPU 优先三维地球 SDK：从全球视角到街道，再无缝进入建筑、楼层、房间，同一个 `GeoViewer` 提供地球、图层、点位、室内和交互。

> 0.x 阶段次版本号可以有破坏性变更，每一项都记在 [CHANGELOG](https://github.com/Yoy0o/TerraView/blob/v0.2.0/CHANGELOG.md)。公共 API 分为稳定 / 高级 / 内部三级，见 [docs/api.md](https://github.com/Yoy0o/TerraView/blob/v0.2.0/docs/api.md) §2。

## 安装

```bash
npm install terra-viewer three@0.187.0 3d-tiles-renderer@0.5.4
npm install -D @types/three@0.187.0   # TypeScript 宿主
```

也可以用本页附带的 `terra-viewer-0.2.0.tgz`：`npm install ./terra-viewer-0.2.0.tgz three@0.187.0 3d-tiles-renderer@0.5.4`。

```ts
import 'terra-viewer/style.css';
import { AWS_TERRARIUM, GeoViewer, IMAGERY_PRESETS } from 'terra-viewer';

const viewer = await GeoViewer.create({
  container: document.getElementById('map')!,
  imagery: IMAGERY_PRESETS[0].create(),
  terrain: AWS_TERRARIUM,
  initialView: { longitude: 116.397, latitude: 39.916, height: 3000, heading: 0, pitch: -40 },
});
```

## 这一版有什么

**地球**
- WebGPU 优先（自动回退 WebGL 2），着色器全部用 TSL；ECEF 世界坐标、float64 模型视图矩阵、逐瓦片原点，从太空到街道不抖动。
- 四叉树影像与地形：XYZ 底图预设与叠加层，Terrarium / Terrain-RGB / Cesium World Terrain / quantized-mesh 地形，EGM96 改正为椭球高。加载调度借鉴 CesiumJS，缩放、加载时不闪烁、不出空洞。
- 物理大气与真实光照（按日期的太阳位置、昼夜、晨昏），建筑和 3D Tiles 的光色、天光、空气透视跟随同一个大气模型。
- 云：全球的云壳，以及 300 km 以下的**体积云**（可以飞进云里，云被山体和建筑遮挡，开光照时投下随风移动的云影）。

**数据图层**
- OGC 3D Tiles（Draco / KTX2 / Meshopt、Cesium ion、Google 真实感 3D Tiles）：WebGPU 下的渐显，按显存档位的预算与自适应降精度，要素拾取、属性与高亮。
- **高斯泼溅（3DGS）**：`.ply` / `.splat` / `.spz` 在 Worker 里解码，地理锚定、拾取、裁剪，可以绑定到建筑层级。
- GeoJSON 矢量（Worker 解析、贴地栅格化、注记避让、点击查询），点位标注（8 种顶牌样式、属性规则、层级聚合）。

**室内 / BIM**
- `*.building.json` 建筑文档：建筑 → 楼层 → 房间 / 设备 / 构件，程序生成或 glTF 模型，楼层模型按需加载、按显存预算卸载。
- 层级导航（双击进入、右键 / Esc 返回，可取消、视点缓存），可替换的层级控制策略，选择器查询与批量样式，设备合批（1 万个设备约 40 次绘制）。
- **层级绑定**：高斯泼溅、3D Tiles 图层挂到某栋楼、某一层，进入对应层级时才加载和显示。
- 日照阴影、楼层环境光遮蔽、描边与发光、透明顺序无关混合（WebGPU）、层级切换时按深度重投影的溶解过渡。

**场景与交互**
- 统一交互事件（选择器冒泡、优先级、标签、暂停、`preventDefault`），GPU 拾取缓冲。
- 相机：零 roll、俯视不翻转、缩放保持航向和俯仰；飞行、环绕、开场动画、导航命令（`viewer.navigation`，无 UI）。
- **局部场景（沙盘）**：只显示一块区域，边缘土层侧壁，相机围着它活动。

**嵌入与运行**
- 容器任意大小、同页多个 viewer、`dispose()` 后 Worker 和监听归零；样式类名统一 `tv-` 前缀，主题用 `--tv-*` 变量。
- 显存档位（`low` / `medium` / `high` / `ultra`，按适配器自动识别）、显存估算 `viewer.memory`、诊断快照 `viewer.snapshot()`。
- 画面静止 1 秒后做静止超采样，画完就停画（CPU 降到原来的约 1/6）；`requestRender()` / 调色。
- 加载状态与错误事件（`viewer.loadState`、`idle`、`error`），`TerraViewError` 带稳定的错误码；界面文案内置 `zh-CN` 和 `en`。

## 从 0.1.0 原型升级

0.1.0 是迁移前（three-geo-global）的原型，没有对外发布。用过它的代码需要注意下面这些破坏性变更，细节见 CHANGELOG 各节。

| 方面 | 变化 |
| --- | --- |
| 包与样式 | 从 `terra-viewer` 导入，样式单独引入 `terra-viewer/style.css`；`three`、`3d-tiles-renderer` 改为 peer 依赖 |
| 类名与主题 | 类名统一 `tv-` 前缀（`.tv-canvas`、`.tv-marker` …），状态类 `.tv-selected` 等；顶牌改读 `--tv-font` / `--tv-text` / `--tv-muted` / `--tv-card-bg` / `--tv-accent` |
| 容器与键盘 | 顶牌层相对容器定位（不再 `position: fixed`）；相机键盘只在 viewer 有焦点时生效 |
| 文案与错误 | 影像预设的 `name` 改为 `label: LocalizedText`；`globe.imageryErrorMessage` → `globe.imageryError`；SDK 抛出的错误是英文消息加 `code` |
| 导出 | 一批内部实现不再从入口导出（`geoidUndulation`、`WebMercatorTilingScheme`、聚合树函数等，清单见 docs/api.md §3.9） |
| 选中与悬停 | 不再改实体的自发光，改为描边（`indoor.selectOutline` / `hoverOutline`、`viewer.effects.defineOutline`） |
| 层级过渡 | `.tv-crossfade` 元素和 `FrameCrossfade` 去掉，过渡改在 GPU 上做（`viewer.levelTransition`） |
| 楼层模型 | 楼层第一次显示时才加载；`indoor.add()` 之后要用模型先 `await building.modelsLoaded(entity)`，或设 `lazyModels: false` |
| 停画 | 画面静止后不再画帧：绕过 SDK 直接改 `viewer.scene` 里的对象、材质后要调用 `viewer.requestRender()` |
| 统计 | `stats.drawCalls` / `triangles` 只算场景 pass |

## 兼容性

| 项 | 要求 |
| --- | --- |
| peer 依赖 | `three` 0.187.x、`3d-tiles-renderer` 0.5.x（three 不按 semver 发布，范围锁在 r187） |
| 浏览器 | Chrome / Edge 113+ 走 WebGPU；其他支持 WebGL 2 的浏览器自动回退（`forceWebGL` 可强制）。透明顺序无关混合、GPU 拾取缓冲只在 WebGPU 下 |
| 打包工具 | 只有 ES 模块。Vite 8、webpack 5 已实测（含 Worker 和 Draco / KTX2 / Meshopt 解码） |
| 构建本仓库 | Node 20.19+ / 22.12+ |

## 已知限制

- 影像只支持 Web Mercator 瓦片；3D Tiles 的影像叠加插件在 WebGPU 下不可用，点云在 WebGPU 下是 1 像素点。
- 高斯泼溅整体加载（没有分块流式）、不写深度；真实 GPU 上的帧率尚未系统测量。
- 室内尚不支持 IFC 直读、剖切与室内导航。
- 默认底图 / 地形服务只用于开发演示，生产环境请使用自有服务或取得授权；示例国界数据不是审定地图。

完整列表见 [README](https://github.com/Yoy0o/TerraView/blob/v0.2.0/README.md#已知限制)。
