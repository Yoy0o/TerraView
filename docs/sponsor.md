# 赞助支持

简体中文 | [English](./en/sponsor.md)

TerraView 是 Apache-2.0 许可的免费开源项目，由个人维护者利用业余时间开发和维护。如果它在你的项目里帮上了忙，欢迎赞助。

## 赞助会用在哪里

- **新功能**：路线图上的矢量瓦片（MVT）、IFC 直读、IoT 数据管线、测量与剖切等。
- **真实设备上的测试**：集成显卡、独立显卡、移动端 GPU 上的画面与性能核对，这些在 CI 的软件渲染里测不到。
- **文档与示例**：使用手册、可运行示例、英文版文档的持续维护。
- **数据与服务**：演示和示例用到的地图、地形、3D Tiles 数据的托管与授权。

## 企业赞助与技术支持

需要定制开发、私有部署指导、功能优先排期或技术咨询的团队，请[开一个 issue](https://github.com/Yoy0o/TerraView/issues/new/choose) 简单说明来意，维护者会与你联系后续的沟通方式。企业赞助者可以在 README 和文档站点上展示标识。

## 不花钱的支持

- 在 GitHub 上点一个 **Star**，让更多人看到它。
- 在你的项目里用起来，把遇到的问题、性能数据和改进建议[反馈回来](https://github.com/Yoy0o/TerraView/issues)。
- 提交代码或文档（见[贡献指南](https://github.com/Yoy0o/TerraView/blob/main/CONTRIBUTING.md)）。
- 写文章、做分享时提到 TerraView。
